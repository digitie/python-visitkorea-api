## 변경과 검증

공개 KrTourApiClient/TourApiHubClient/TourApiServiceClient를 네이티브 비동기로 통합했다. 모든 최초 GET·연결 재시도·상태 재시도·리디렉션 송신에 동일 AsyncTokenBucket을 적용한다. Hub 전 서비스가 버킷/세션을 공유하고 기본 5 TPS이며 capacity=1을 주입해 초기 버스트를 없앨 수 있다. 공개 인자, 도메인 모델/좌표/KST, 27개 서비스·211개 오퍼레이션을 보존했다.

- 전체 오프라인: 140개와 하위 테스트 14개 통과, 커버리지 95.47%. RuntimeWarning을 오류로 처리했다.
- ruff 전체, mypy 소스 23개, compileall 소스/테스트/UI 통과.
- 적대적 리뷰 A: 독립 모의 테스트 24개 승인. 토큰/송신 수, 재시도, 리디렉션, 종료·취소·인증 변경 경계, 캐시 잠금 누수, 응답 숫자 변환, 키 반사/로그 동시성 검증.
- 적대적 리뷰 B: 기준/변경 코드 각각 모의 도메인 HTTP 254회, 디버그 2회, 문서 예제 43개(모의 HTTP 63회), CLI 9명령·오류2경로와 UI 성공/인증오류 경로 승인.
- 발견한 캐시 잠금 누수, 파싱 전 마스킹의 숫자 훼손, 리디렉션 로그 키 노출, 독립 클라이언트 종료 API 누락, kwargs 키의 context 노출을 수정하고 재승인받았다.

## 두 리뷰 승인 후 라이브 E2E

`VISITKOREA_RUN_LIVE=1`과 로컬 환경 인증값으로 tests/test_live.py를 실행했다. 실제 비동기 HTTP 요청을 사용했고 인증값은 기록하지 않았다.

**7개 통과 / 1개 인증 거부 skip** (4.85초).

- 국문 지역 코드, 검색→상세 연결, 반려동물 조회, TPS/재시도 설정, 캐시 동일 인스턴스, GoCamping 타입 응답, Hub 디버그 지역 코드 조회 통과.
- 영문 관광정보 `EngService2/areaCode2`: **HTTP 403**, TourApiAuthError. 데이터 성공으로 집계하지 않는다.

영문 API의 403은 기존 사용자 예외 승인 범위에 없으므로 보고 후 **머지 보류**한다. 27개 서비스의 모든 실서버 오퍼레이션을 실행한 것은 아니다. 소유 세션은 각 테스트의 async context에서 종료했다.
